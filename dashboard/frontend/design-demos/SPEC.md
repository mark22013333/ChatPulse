# ChatPulse 後台介面改版 · 三版 mockup 共用 spec

> 這份是三個版本的**唯一共同輸入**。三版只換設計詮釋，內容、尺寸、骨架、token 規則完全一致，方便橫向對比。

## 1. 這是什麼

ChatPulse 是給工程團隊用的 Google Chat 輔助工具。使用者（產品術語叫 **Viewer**）用自己的 Google 帳號授權，能做三件事：

1. **摘要工作台** — 從自己加入的 436 個 Space 裡選一個，抓最近 N 則訊息產出結構化摘要，可推播回 Chat
2. **Mention 收件匣** — 跨所有 Space 找出誰 @ 了本人，待處理／已處理兩種狀態；針對一則 Mention 產生 Draft Reply（建議回覆），改完以本人身分送回原討論串
3. **設定中心** — 回覆語氣、個人寫作風格（Persona）、常用提示詞、參考專案、Space 偏好、用量

現在要把它從「頂列膠囊頁籤 + 三欄」的工具型版面，改成**後台管理介面（admin console）風格**，因為後續要加統計儀表板、知識庫檢索，以及一個讀 Google Chat + 專案 git 紀錄產出「一週工作事項與工時」的週報模組。

**做這份 mockup 的目的**：在動 React 程式碼之前，先讓使用者看到三個方向的真實視覺，選定一版（或混搭）再實作。

## 2. 輸出規格

- **單一 HTML 檔**，純 HTML + CSS，零 JS 框架。只允許一小段 vanilla JS 做明暗主題切換
- 檔名：`v1-restrained.html` / `v2-standard.html` / `v3-dense.html`（各自的 agent 只做自己那一版）
- **視窗 1440×900** 設計，要能在這個尺寸不出現水平捲軸
- 明暗兩主題都要做。切換方式：`<html class="dark">` 的有無，右上角一顆切換鈕
- 字型 stack（專案用 Geist，mockup 用系統字近似即可）：
  - sans：`'PingFang TC', 'Hiragino Sans CNS', 'Noto Sans TC', system-ui, sans-serif`
  - mono：`ui-monospace, 'SF Mono', Menlo, Consolas, monospace`
- 圖示：inline SVG 畫 lucide 風格線性圖示（stroke-width 1.5~2，24×24 viewBox）。**不要用 emoji 當 UI 圖示**

## 3. 佈局骨架（三版共用）

由左到右四個區域：

```
┌────────┬──────────────┬────────────────────┬──────────────┐
│ 主導覽  │ 上下文欄      │ 主內容區            │ 證據欄        │
│ SideNav│ Space 清單    │ 摘要工作區          │ 證據 + 歷史   │
│ 56/200 │ 288px         │ flex-1 (min 0)      │ 320px        │
└────────┴──────────────┴────────────────────┴──────────────┘
          ↑ 頂部橫跨主導覽以右：TopBar 高 48px（麵包屑 + 全域動作）
```

- **主導覽（SideNav）**：`<nav aria-label="主導覽">`，項目是 `<a>` 不是 button，當前項 `aria-current="page"`。項目：摘要工作台、Mention 收件匣（帶待處理數字 6）、統計（灰階 disabled，標示「即將推出」）、週報（同樣 disabled）、設定。底部放主題切換與登出。
- **TopBar**：高 48px，橫跨主導覽右側全寬。左邊麵包屑「摘要工作台 › 李姿誼Sica Lee」，右邊：⌘K 命令面板、證據欄開關、使用者名「鄭浩宇」
- **上下文欄**：288px，Space 搜尋框 + 虛擬清單（畫 14 筆就好）+ 底部狀態列「顯示 436 / 436」「即時資料」
- **主內容區**：工具列 + 摘要卡片 + Action Items
- **證據欄**：320px，歷史 Summary 清單 + Token 用量表

**這一頁只做「摘要工作台」這一個畫面。**不要做 Mention 收件匣或設定頁——一個畫面就足以判斷方向。

## 5. 色彩系統（硬約束，違反等於白做）

專案有守門測試會掃描原始碼，以下不是風格建議：

1. **所有顏色寫成 CSS 自訂屬性，值一律用 `oklch()`。全檔不得出現任何 hex（`#xxx`）、`rgb()`、`hsl()`。** 包含陰影裡的顏色。
2. **不得使用 Tailwind 具名色的字面（`amber`／`stone`／`orange`／`slate`… 這些字串不要出現在 class 名或註解以外的地方）**。這份 mockup 不用 Tailwind，手寫 CSS，所以只要守住「顏色都走 var(--token)」即可。
3. 色彩方向：**暖中性**（背景與表面走暖灰，不是冷藍灰）+ 一個暖色 accent。

### 四個表面（這次改版的核心）

現況的階層是靠橫向規線分群，這次要改成**靠表面填色分層**。四個表面由低到高：

| token | 用途 |
|---|---|
| `--background` | 整個 app 的底 |
| `--surface` | 內容面板、卡片 |
| `--raised` | 浮起的東西：工具列、輸入框、下拉、當前選取項 |
| `--muted` | 凹陷的東西：表格斑馬列、disabled 底、標籤底 |

三版的差別之一就是這四階的 ΔL（明度落差）拉多開，見第 7 節。

### 前景與規線

- `--foreground` 主文字、`--fg-dim` 次文字、`--fg-subtle` 第三層（時間、計量單位）
- `--line` 純裝飾分隔線與卡片邊框、`--line-strong` 較重的邊框
- `--line-evidence` **承載語意**的規線（實線＝完整、虛線＝降級、點線＝缺值），對比必須 ≥3:1

### 語意色（只有三個，不准多）

- `--signal` = accent，只用在「可互動」與「當前選取」
- `--caution` 警示
- `--destructive` 危險／錯誤

⚠️ **這三個的色相必須拉得開**。暖色系的陷阱：accent 若取琥珀 h70，會與警示色 h75 撞在一起，在 3px 邊框或小 chip 上分不出來。三版各試一個 accent 色相位置（見第 7 節），並且：**狀態的第一區分要靠線型與字符，顏色只是冗餘**。

### 對比門檻（WCAG 2.x 相對亮度，明暗兩主題都要過）

| 用途 | 門檻 |
|---|---|
| 決策性文字（摘要正文、標題、數值） | ≥ 7:1 |
| 次級文字與標籤（時間、副標） | ≥ 4.6:1 |
| 承載語意的規線、focus 環、字符指示器 | ≥ 3:1 |
| disabled 文字 | ≥ 2:1 |
| 純裝飾分隔線 | 無要求 |

**每個前景色要對四個表面各算一次**，不是只對 `--background` 算。在 HTML 最底部放一個 `<details>` 摺疊區，列出你算過的對比表（前景 × 表面 × 明暗），寫明用了什麼算法。算錯比不算更糟，算不準的就標「未驗算」。

## 6. 設計原則（衝突時依序裁決）

1. **顏色是稀有資源**：全站只有一個訊號色 + 一個錯誤色。不要給每個功能一個顏色。
2. **狀態先用線型與字符，顏色只是冗餘**：實線／虛線／點線 = 完整／降級／缺值。色盲使用者不靠顏色也要讀得懂。
3. **全站最大的字是一個數字**：字級上限 22px，且只給計量值（如 Token 用量的 240,275）。標題不得比它大。
4. **等寬字只服務對齊**：space id、model id、數值表格用等寬；**CJK 一律不用等寬**。
5. **不加漸層**。
6. **不給每張卡片同一種灰陰影** — 卡片階層靠表面填色差 + 邊框做，不是靠 box-shadow 疊一層灰。真要用陰影，只給浮層（下拉、對話框）。
7. **不用 all-caps 小標籤**（`SECTION TITLE` 這種）。
8. **不用中點 `·` 當分隔符** — 改用間距、1px 豎線，或直接換行。（現有實作還在用，這次要改掉。）
9. **不用 tooltip 承載唯一資訊** — 要讓人知道的事就寫在畫面上。
10. 資訊密度偏高是對的（這是工作台不是行銷頁），但密度來自**有內容的資訊**，不是裝飾性圖示。

## 7. 三個版本的差異參數

三版共用上面全部，只有這三個維度不同：

| | **v1 克制** | **v2 標準** | **v3 密實** |
|---|---|---|---|
| 主導覽 | icon rail 56px（只有圖示 + 底部 tooltip-free 的文字縮寫），當前項用左側 3px 實心條標示 | 200px 常駐展開，圖示 + 文字 + 待處理數字 badge | icon rail 56px，但 hover 時整塊向右浮出成 200px 疊在內容上（畫兩個狀態：收合態為主，另在頁面下方附一張浮出態的示意） |
| 卡片強度 | **輕**：`--surface` 與 `--background` 的 ΔL 極小（≈0.01），主要靠 1px 邊框界定卡片 | **中**：ΔL ≈ 0.025，填色差看得出來，邊框較淡 | **重**：ΔL ≈ 0.04，且每張卡片有自己的標頭列（`--muted` 底、左右 padding 與內容齊），間距整體縮 20%，Token 用量與 Action Items 改成真正的表格（有表頭、斑馬列） |
| accent 色相 | **銅 h50** 左右 | **琥珀 h70** 左右 | **赤陶 h40** 左右 |

每版在 HTML 最上方用註解寫明自己是哪一版、三個參數各取了什麼值。

## 8. 不要做的事

- 不要引用任何外部 CDN（字型、CSS、JS 都不要）— 必須能離線雙擊開啟
- 不要做 Mention 收件匣或設定頁，只做摘要工作台一個畫面
- 不要編造內容 — 第 4 節有什麼就用什麼，要補空位就留白，不要生假資料
- 不要用 emoji 當 UI 圖示（摘要正文裡的 emoji 是內容，保留）
- 不要做響應式 — 這份只為 1440×900 設計
