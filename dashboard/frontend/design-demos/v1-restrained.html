算法

每個 token 的 oklch(L C H) 值，依 Björn Ottosson 的 OKLab 反轉係數轉成 LMS′ （l′ = L + 0.3963377774×a + 0.2158037573×b 等三式，a = C×cos H、b = C×sin H）， 三次方得到 LMS，再乘 LMS→linear-sRGB 矩陣得到線性 RGB（超出 0~1 者截斷，本檔所有 token 皆在色域內）。 線性 RGB 直接套 WCAG 2.x 相對亮度 Y = 0.2126R + 0.7152G + 0.0722B （已是線性值，不需再做 sRGB 反 gamma），對比度 (Y亮 + 0.05) / (Y暗 + 0.05)。 計算用 Python 實跑，非手估；數值四捨五入到小數二位。

門檻依 spec 第 5 節：決策性文字 ≥ 7:1、次級文字與標籤 ≥ 4.6:1、承載語意的規線／focus 環／字符 ≥ 3:1、disabled 文字 ≥ 2:1、純裝飾分隔線無要求。
